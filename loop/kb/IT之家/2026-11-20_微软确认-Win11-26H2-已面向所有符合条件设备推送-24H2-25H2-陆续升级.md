# 微软确认 Win11 26H2 已面向所有符合条件设备推送，24H2、25H2 陆续升级

IT之家 11 月 20 日消息，微软宣布，自当地时间 2026 年 11 月 18 日起，正式扩大 Windows 11 26H2 版本的自动推送范围，符合升级条件的设备将逐步通过 Windows Update 自动获取更新。

微软表示，Windows 11 26H2 现已面向所有符合条件的设备开放。该版本包含此前在 Windows 11 24H2 和 25H2 中公布的全部新功能，并采用服务技术（Servicing Technology）交付，可提供较快的安装体验。

自 2026 年 10 月下旬起，所有符合 Windows 11 升级条件的设备均已可以通过手动检查更新获取 26H2 版本。此次扩大自动推送范围，意味着用户不再需要主动检查更新或手动启动下载，系统将根据 Windows Update 设置逐步自动获取并安装更新。

微软指出，此次自动推送适用于个人设备以及未纳入 IT 集中管理的企业设备。对于由 IT 部门管理的设备，更新推送仍取决于组织自身的更新管理策略。

用户也可以通过手动方式检查更新：打开 Windows 11「设置」中的「Windows 更新」，点击「检查更新」。如果设备已经获得 Windows 11 26H2 更新资格，页面将显示「下载并安装」选项。

IT之家提醒，用户可以开启「在最新更新可用后立即获取」选项，以便在更新向设备开放后尽早收到相关版本。
