# OpenAI 开放 GPT-Live-1.1 API：支持实时双向对话，智能体可边聊天边处理复杂任务

IT之家 11 月 20 日消息，OpenAI 今日宣布向开发者开放 GPT-Live-1.1 API 语音模型，允许第三方开发者将其集成到自己的应用程序中，构建能够实时聆听、回应并执行复杂任务的 AI 语音智能体。

据 OpenAI 介绍，GPT-Live-1.1 是 GPT-Live-1 的升级版本，具备全双工语音交互能力，可以同时聆听和说话，不必等待用户完整说完一句话才开始处理。该模型能够识别用户说话过程中的停顿、打断和语速变化，并实时判断应该继续聆听还是作出回应。

IT之家注：GPT-Live-1.1 自 2026 年 10 月 15 日起已成为 ChatGPT Plus 及更高级别订阅用户的默认语音模型。此次 API 开放，则进一步将相关能力提供给第三方开发者。

在具体能力方面，OpenAI 表示，GPT-Live-1.1 改进了多语言语音处理、指令遵循能力和语音保真度，能够更可靠地处理字母、数字等需要精确识别的信息，减少语音交互过程中出现的理解偏差。

此外，该模型支持将需要更深入推理或工具调用的任务委托给开发者选择的后端模型。开发者既可以使用 OpenAI 的模型，也可以接入第三方模型。后端模型在处理复杂任务时，语音对话仍然可以继续进行，无需中断当前交互。

这意味着，开发者可以将实时语音交互与后端模型的推理、工具调用能力结合起来，让语音智能体在回答用户问题的同时，处理需要多步骤执行的复杂工作流。

根据 OpenAI 官方 API 文档，GPT-Live 系列采用全双工架构，能够直接处理输入和输出音频，减少传统语音系统中语音识别（STT）、大语言模型（LLM）和语音合成（TTS）串联所产生的延迟。

OpenAI 已提供 GPT-Live-1.1 API 相关技术文档及接入指南，开发者可以通过 OpenAI 开发者平台了解模型能力、配置方式和具体使用方法。
